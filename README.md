# vuln-nextjs-demo

**Intentionally vulnerable** Next.js app used as a live target for [phaz-lite](https://github.com/phazww/phaz-lite).

⚠️ Every "secret" in this repo is **fake and harmless**, planted on purpose to demonstrate what phaz-lite catches. Do not copy any pattern from this code into a real project.

Live demo: https://phazww.github.io/vuln-nextjs-demo/

Run the scan yourself:

```bash
npx phaz-lite https://phazww.github.io/vuln-nextjs-demo/
```
